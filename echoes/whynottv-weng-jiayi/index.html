WhynotTV：对话翁家翌

成长阶段 · System 1 / System 2

  • System 1（系统1）

    是快速、自动且直觉性的思考，它不怎么费力，例如瞬间识别出朋友的脸或回答“2+2=？”。

  • System 2（系统2）

    则是慢速、需要专注和分析的思考，它处理复杂问题，例如计算一道复杂的数学题或规划一次长途旅行。

  • 简单来说，系统1是你的直觉反应，而系统2是你有意识的、深思熟虑的推理过程。

Yoshua Bengio

  • Yoshua Bengio 被誉为“深度学习三巨头”之一，与 Geoffrey Hinton 和 Yann LeCun 共同获得了计算机界的最高荣誉——图灵奖。他几十年来致力于神经网络的研究，其团队在序列建模和注意力机制上的贡献，为后来 ChatGPT 等大语言模型的诞生奠定了核心理论基石。

成长阶段 · 本科：影响力与确定性

  • 开源作业的策略

    将所有作业开源至 GitHub。 打破信息差：追求信息平等，帮助不擅长搜集信息的人。 建立个人IP：提高曝光度，认为被大众记住比给母校捐楼更有社会影响力。

  • 误打误撞的 RL 之路

    本想研究 GAN，却误入 RL（强化学习）领域，因其趣味性坚持至今。

  • Hacking 精神

    享受以“上帝视角”构建脑中场景的过程。

  • 暑研转折点

    在 Yoshua Bengio 获图灵奖前申请其暑研，被安排至 NLP 方向。冥冥之中完成了 RL + NLP的路径布局，贴合 OpenAI 的技术路线。

  • 价值观

    GPA 并非唯一：简历上三四年后就消失的数字，不应是大学唯一的评价体系。 影响力至上：创造有用的东西并分享，哪怕亏钱，只要产生影响力就有价值。 游戏人生：人生的结算分数是“记得你名字的人数”。

John Schulman

  • John Schulman 是人工智能领域的顶尖科学家，也是 OpenAI 的联合创始人之一。他是强化学习领域的关键领袖，主导开发了近端策略优化（PPO）算法，该算法现已成为强化学习中最常用、最稳定的标准算法。更重要的是，他在 OpenAI 领导了强化学习人类反馈（RLHF）团队，这一技术正是让 ChatGPT 能够听懂人类指令、并进行自然对话的核心基石。

马尔可夫过程

  • 马尔可夫过程是一类随机过程，其核心假设是未来状态只依赖于当前状态，而与更早的历史无关，这被称为马尔可夫性。它通常用状态集合和状态转移概率来描述系统的演化过程。确定性的马尔可夫过程是一种特殊情况：在给定当前状态（和动作）后，下一状态是唯一确定的，而不是由概率分布采样得到。

    未来的我帮助现在的我，现在的我成就未来的我。我也深有感触，我时常和未来的我对话，他会告诉我一些事情。
