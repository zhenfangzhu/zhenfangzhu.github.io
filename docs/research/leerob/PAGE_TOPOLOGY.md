# Homepage Topology

Reference: `https://leerob.com/` sampled on 2026-08-26.

1. A page shell uses restrained responsive padding and centers one content frame.
2. A reading column contains the title, compact index, biography, and all textual sections.
3. A sticky visual column appears only at desktop widths of 1100px and above.
4. The content is organized into two top-level worlds:
   - Reality: focus, education, tools, and contact.
   - Dreams: a self-contained introduction and archive entry.
5. There is no fixed navigation, card grid, mode switch, or scroll-driven state machine.

The desktop layout is a two-column editorial spread. Tablet and mobile collapse to the reading column and hide the visual.
