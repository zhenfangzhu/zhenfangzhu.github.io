# 01.me `/whoami/` — Page Topology

Reference URL: `https://01.me/whoami/`

This document records the reference structure used to inform—not copy—the Zhu Zhenfang homepage.

1. **Utility navigation** — blog return link on the left; research, scholar, and CV links on the right. Static.
2. **Identity profile** — vertical portrait, name, role, English biography, Chinese biography, and primary links. Static two-column desktop layout; stacked mobile layout.
3. **Contact strip** — email and social links in a bordered horizontal surface. Static with link hover states.
4. **Section index** — inline anchored links for profile sections. Anchor navigation.
5. **Current organization** — heading and descriptive card. Static content.
6. **Publications and output** — dense long-form lists grouped by type. Static content with outbound links.
7. **Education, awards, and activities** — chronological dense lists. Static content with anchors.
8. **Footer** — copyright and related links. Static.

The Zhu Zhenfang implementation will use only the first four structural ideas plus sections supported by real user content.
