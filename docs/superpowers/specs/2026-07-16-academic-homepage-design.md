# Academic Homepage Redesign

## Positioning

The homepage presents Zhu Zhenfang as a technical builder working at the intersection of research, engineering, and entrepreneurship. The first screen establishes technical credibility; entrepreneurial philosophy appears later and in a restrained form.

## Information Architecture

1. A compact sticky navigation with About, Focus, and Highlights.
2. A two-column introduction with portrait, name, role, education, contact, and external profile links.
3. A concise biography focused on education, engineering practice, and current AI direction.
4. Research & Engineering Focus cards for AI infrastructure, LLM systems, and open-source engineering.
5. Highlights covering USTC education, current AI entrepreneurship, and collaboration availability.
6. A minimal footer with the canonical site URL and GitHub link.

Publications and Awards remain hidden until real entries are available. Empty links and placeholder claims are removed.

## Visual System

- Editorial academic style with generous whitespace and a restrained navy/blue palette.
- Newsreader for display headings and Mulish for body/interface text, with robust system-font fallbacks.
- Maximum reading width of approximately 70 characters and a consistent 8px spacing rhythm.
- Subtle borders and surface changes replace colorful alert boxes and heavy gradients.
- Motion is limited to short hover/focus transitions and disabled for reduced-motion users.

## Responsive and Accessibility Requirements

- Mobile-first layout with no horizontal scrolling at 375px.
- Visible skip link, sequential heading hierarchy, semantic landmarks, and visible keyboard focus.
- Meaningful portrait alt text and accessible labels for icon-only links.
- Minimum 44px interactive targets on compact screens.
- Fixed navigation must not obscure anchored sections.

## Domain

Use the active GitHub Pages URL, `https://zhuzhenfangx.github.io/`, for canonical, Open Graph, and sitemap metadata. A future custom domain can replace it after registration and DNS configuration.

## Scope

The redesign stays dependency-light and preserves the existing static HTML + Markdown architecture. It does not invent publications, awards, projects, affiliations, or social profiles.
